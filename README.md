# eBook to PDF Converter

電子書籍の閲覧画面を自動キャプチャし、PDFへと変換・結合するWindows向けデスクトップツールです。

---

## 起動方法

`run.bat` をダブルクリックして起動します。  
Miniconda / Anaconda の `base` 環境を自動検出し、アクティベートした上で実行されます。

コマンドラインから起動する場合は以下の通りです：
```bash
conda activate base
python app.py
```

## 主な機能

- マウスドラッグによる範囲指定
  - ボタン操作で画面全体にオーバーレイが表示され、対象ウィンドウの表示領域をドラッグで指定できます。
- マルチモニターおよびDPI対応
  - Windowsの拡大倍率（125%、150%等）や複数モニター環境でも、座標のズレなくキャプチャできます。
- プレビューとPDF設定
  - キャプチャ完了後にサムネイル一覧で全ページを確認できます。
  - 綴じ方向（左綴じ/横書き、右綴じ/縦書き・漫画）や表示レイアウト（単一ページ、見開き）を選択して保存可能です。
- 自動ページめくりと章番号の自動加算
  - キーボード操作のエミュレーションによる自動ページ送りを行います。
  - PDF保存完了ごとに章番号（Chapter）が自動で +1 されます。
- 設定の自動保持
  - 指定した範囲座標、ファイル名、章番号、ページ数、待機時間、綴じ方向設定などは `config.json` に保存され、次回起動時にも復元されます。
- 緊急停止（Fail-Safe）と途中キャンセル機能
  - キャプチャ中に「Stop Capture」ボタンを押すか、マウスカーソルを画面の四隅（左上端など）へ素早く移動させることで、いつでも即座に処理を中断できます。

## 必要環境とセットアップ

- OS: Windows 10 / 11
- Python: 3.8 以上 (Miniconda / Anaconda 推奨)

必要なライブラリが未インストールの場合は、ターミナルで以下を実行してください：
```bash
pip install customtkinter pyautogui pillow
```

---

## 操作手順

1. `run.bat` をダブルクリックしてアプリを起動します。
2. 「1. Select Region」をクリックし、電子書籍のページ表示領域をドラッグして囲みます（Escキーまたは右クリックでキャンセル可能）。
3. ファイル名、章番号、ページ数、めくり待機時間（Interval）を入力・確認します。
4. 「2. Start Capture」をクリックします。5秒のカウントダウンが始まるので、その間に電子書籍ビューアーをクリックして最前面にしてください。
5. キャプチャ完了後、プレビュー画面が開きます。ページ内容を確認し、綴じ方向・レイアウトを選択した上で「保存場所を指定してPDF保存」をクリックします。

## スタンドアロンEXEの作成 (build.py)

Python環境のないPCで単体動作する `.exe` ファイルを作成する場合は、以下を実行します：

```bash
pip install pyinstaller
python build.py
```
ビルド完了後、`dist/` フォルダ内に `eBookToPDF.exe` が生成されます。

## トラブルシューティング

- 起動しない場合:
  - 必要なライブラリ（`customtkinter`, `pyautogui`, `pillow`）がインストールされているか確認してください。
- 途中で強制中断したい場合:
  - マウスカーソルを画面の左上隅に素早く移動させてください。Fail-Safe機能が作動して即座に停止します。
- 画面座標がズレる場合:
  - アプリ側でDPI自動補正を行っていますが、拡大倍率の異なるマルチモニター環境で不整合が起きる場合は、メインモニターに対象ウィンドウを配置してご利用ください。
