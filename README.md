電子書籍ビューアーの画面を自動でスクリーンショット撮影し，ページめくりを行い，最終的にPDFファイルとして結合・保存するPythonツールセットです．

# 1 ファイル構成

  * **`ebookmouse.py`**: 座標取得ツール．スクリーンショットを撮りたい範囲（左上と右下）の座標を調べるために使用します．
  * **`ebook.py`**: メインスクリプト．設定した座標とページ数に基づいて自動撮影・PDF変換を行います．

# 2 事前準備

## 2.1 必要なライブラリのインストール

このツールは `pyautogui` (マウス・キーボード操作) と `Pillow` (画像処理) を使用します．以下のコマンドでインストールしてください．

```bash
pip install pyautogui pillow
```

## 2.2 電子書籍ビューアーの準備

  * KindleやWebビューアーなど，電子書籍を開きます．
  * **ウィンドウの位置を固定**してください（撮影中にウィンドウを動かすとズレます）．

-----

# 3 使い方

## 3.1 Step 1: 撮影範囲の座標を調べる (`ebookmouse.py`)

まず，スクリーンショットを撮りたい範囲（本のページ部分）の座標を取得します．

1.  `ebookmouse.py` を実行します．
    ```bash
    python ebookmouse.py
    ```
2.  マウスカーソルを動かすと，ターミナルにリアルタイムで `X: 〇〇 Y: 〇〇` と座標が表示されます．
3.  以下の2点の座標をメモしてください．
      * **左上 (Start Point)**: 画像として切り抜きたい範囲の左上の角
      * **右下 (End Point)**: 画像として切り抜きたい範囲の右下の角
4.  確認が終わったら `Ctrl + C` で終了します．

## 3.2 Step 2: 設定の変更 (`ebook.py`)

`ebook.py` をテキストエディタで開き，以下の「設定項目」セクションを自分の環境に合わせて書き換えてください．

```python
# --- 設定項目 ---

# 章番号などを指定（ファイル名の生成に使われます）
CHAPTER = "7"

# 【重要】スクリーンショットの一時保存先（自分のPCのパスに変更してください）
PNG_SAVE_DIR = r"C:\Users\YourName\Desktop\TempScreenshots\\" + CHAPTER

# 【重要】完成したPDFの保存先（自分のPCのパスに変更してください）
PDF_SAVE_PATH = r"C:\Users\YourName\Documents\Books\MyBook_" + CHAPTER + ".pdf"

# 撮影するページ数
NUM_PAGES = 12

# ページめくりの待機時間（秒）
# 読み込みが遅いビューアーの場合は長め（2.0〜3.0）に設定してください
INTERVAL = 1.5

# Step 1でメモした座標を入力
X1 = 236   # 左上のX座標
Y1 = 34    # 左上のY座標
X2 = 2396  # 右下のX座標
Y2 = 1552  # 右下のY座標

# PDFの解像度（通常はそのままでOK）
RESOLUTION_DPI = 500.0
```

## 3.3 Step 3: 実行 (`ebook.py`)

1.  電子書籍ビューアーを前面に表示できる状態にします．
2.  `ebook.py` を実行します．
    ```bash
    python ebook.py
    ```
3.  **「撮影開始まで 5 秒...」** とカウントダウンが始まります．
4.  **すぐに電子書籍ビューアーのウィンドウをクリックしてアクティブ（最前面）にしてください．**
5.  マウスから手を離してください．自動で「撮影 → 右キー（ページめくり） → 待機」が繰り返されます．
6.  全ページの撮影が終わると，自動的にPDFへの変換が行われ，プログラムが終了します．

# 4 ⚠️ 注意事項・トラブルシューティング

  * **緊急停止機能 (Fail-Safe):**
      * プログラムが暴走したり，途中で止めたい場合は，**マウスカーソルを画面の四隅（左上など）に素早く移動させてください**．安全装置が働き，プログラムが強制終了します．
  * **ページめくり:**
      * このスクリプトは `Right` キー（右矢印キー）でページをめくります．ビューアーの操作設定が異なる場合は，コード内の `pyautogui.press('right')` を `'left'` や `'space'` などに変更してください．
  * **マウス操作厳禁:**
      * 実行中にマウスを動かすと，関係ない場所をクリックしたり，座標がずれる原因になります．
  * **著作権について:**
      * 作成したデータは**私的利用の範囲内**でのみ使用してください．

-----

# 5 仕組みの解説

1.  `pyautogui.screenshot(region=...)` で指定範囲をキャプチャし，連番のPNGファイルとして保存します．
2.  `pyautogui.press('right')` で次のページへ進みます．
3.  全工程終了後，`PIL` (Pillow) ライブラリを使って，保存されたPNG画像を1つのPDFファイルに結合します．
