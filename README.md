# eBook to PDF Converter (電子書籍PDF化ツール)

電子書籍ビューアーの画面を自動でスクリーンショット撮影し、継続的にページめくりを行い、最終的に1つのPDFファイルとして結合・保存するPythonツールセットです。

## 📁 ファイル構成

- `ebookmouse.py`: **座標取得ツール**。スクリーンショットを撮りたい範囲（左上と右下）の座標を調べるために使用します。
- `ebook.py`: **メインスクリプト**。設定した座標とページ数に基づいて自動撮影・PDF変換を行います。

## ⚙️ 事前準備

### 1. 必要なライブラリのインストール
このツールは `pyautogui` (マウス・キーボード操作) と `Pillow` (画像処理) を使用します。Pythonがインストールされている環境で、以下のコマンドを実行してください。

```bash
pip install pyautogui pillow
```

### 2. 電子書籍ビューアーの準備
- KindleやWebビューアー（ブラウザ）など、対象の電子書籍を開きます。
- **ウィンドウの位置とサイズを固定**してください。撮影中にウィンドウを動かしたりサイズを変更すると、キャプチャ範囲がズレてしまいます。

---

## 🚀 使い方

### Step 1: 撮影範囲の座標を調べる (`ebookmouse.py`)
まず、スクリーンショットを撮りたい範囲（本のページ部分）の座標を取得します。

1. コマンドプロンプトやターミナルで `ebookmouse.py` を実行します。
   ```bash
   python ebookmouse.py
   ```
2. マウスカーソルを動かすと、ターミナルにリアルタイムで `X: 〇〇 Y: 〇〇` と現在の座標が表示されます。
3. 画像として切り抜きたい範囲の以下の2点の座標をメモします：
   - **左上 (Start Point)**
   - **右下 (End Point)**
4. 座標のメモが終わったら `Ctrl + C` でプログラムを終了します。

### Step 2: 設定の変更 (`ebook.py`)
`ebook.py` をテキストエディタで開き、ファイルの先頭にある「設定項目」セクションを自分の環境に合わせて書き換えてください。

```python
# --- 設定項目 ---
CHAPTER = "4"  # 章番号や整理番号（ファイル名の生成に使用）

# 【重要】スクリーンショットの一時保存先フォルダ（絶対パスを推奨）
PNG_SAVE_DIR = r"C:\Users\YourName\Desktop\TempScreenshots\\" + CHAPTER

# 【重要】完成したPDFの保存先パス
PDF_SAVE_PATH = r"C:\Users\YourName\Documents\Books\MyBook_" + CHAPTER + ".pdf"

NUM_PAGES = 18       # 撮影する総ページ数
INTERVAL = 1.5       # ページめくりの待機時間（秒）。読み込みが遅い場合は長めに設定

# Step 1でメモした座標を入力
X1 = 220             # 左上のX座標
Y1 = 124             # 左上のY座標
X2 = 2342            # 右下のX座標
Y2 = 1481            # 右下のY座標

RESOLUTION_DPI = 500.0 # PDFの解像度
```

### Step 3: 実行 (`ebook.py`)
1. 電子書籍ビューアーを前面・指定位置に表示できる状態にします。
2. `ebook.py` を実行します。
   ```bash
   python ebook.py
   ```
3. ターミナルで **「撮影開始まで 5 秒...」** とカウントダウンが始まります。
4. **すぐに電子書籍ビューアーのウィンドウをクリックしてアクティブ（最前面）にしてください。**
5. 以降は**マウスとキーボードから手を離してください**。自動で「画面キャプチャ → 右矢印キー（ページめくり） → 待機」が繰り返されます。
6. 全ページの撮影が終わると、自動的にPDFへの変換が行われ、完了するとプログラムが終了します。

## ⚠️ 注意事項・トラブルシューティング

- **🚨 緊急停止機能 (Fail-Safe)**
  プログラムが暴走したり、途中で強制終了したい場合は、**マウスカーソルを画面の四隅（左上など）に素早く移動**させてください。`pyautogui` の安全装置が働き、プログラムが即座に停止します。
- **ページめくりについて**
  現在のスクリプトは `Right` キー（右矢印キー）でページをめくります。使用するビューアーによっては操作キーが異なる場合があります。その場合は `ebook.py` 内の `pyautogui.press('right')` を `'left'`, `'space'`, `'pagedown'` などに変更してください。
- **マウス操作厳禁**
  実行中にマウスを動かすと、関係ない場所をクリックしたり、座標がずれる原因になります。
- **著作権について**
  本ツールで作成したデータは、**私的利用の範囲内**でのみ使用してください。著作権法を遵守してご利用ください。

## 💡 仕組みの解説
1. `pyautogui.screenshot(region=...)` で指定した画面範囲をキャプチャし、連番のPNGファイルとして一時フォルダに保存します。
2. `pyautogui.press('right')` でキー入力エミュレートによりページをめくります。
3. 全ページの撮影が完了した後、`Pillow (PIL)` ライブラリを使用して、保存された連番PNG画像を1つのPDFファイルに結合します。
